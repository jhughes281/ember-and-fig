# Ember & Fig Houston

Concept storefront for a Houston candle brand that ships worldwide: an "All Candles" collection page with the Aromatic Collection (Sandalwood, Santal Noir, Vanilla Smoke, Spiced Amber, Golden Fig) and a line of candles named for Houston neighborhoods.

Static HTML, CSS and JavaScript in one `index.html`, served by GitHub Pages at https://jhughes281.github.io/ember-and-fig/.

Prices, the currency rates and the studio details are placeholders, and checkout is not connected. Product photos are Unsplash placeholders; see [CREDITS.md](CREDITS.md).
